# Jリーグ 節ごと勝ち点・得失点 比較

J1/J2クラブの節ごとの累積勝ち点・得失点を、今季と過去シーズンで比較する静的サイト。
データは [Jリーグ公式 データサイト](https://data.j-league.or.jp/SFMS01/)（日程・結果）から **APIキー不要** で取得し、
GitHub Actions が `data/*.json` にコミット → GitHub Pages で公開する。

## 機能
- 節ごとの累積(勝ち点/得失点/得点/失点)を今季と過去シーズンで比較。監督の途中交代は線の中心の色で表示
- グラフ下に、1試合ずつの結果(色)・対戦相手の順位・ホーム/アウェイの帯(「対戦相手の順位」は対戦時点/最終順位を切替)
- 順位帯(トップ3/上位/中位/下位)ごとの成績とタイプの目安
- 過去の優勝・2位・3位・降格圏クラブとのペース比較(平均線/個別クラブ)
- 画面下のドラッグエリアで節を移動。クラブごとのカラー(色名はWikipedia記載に基づく近似色)

## セットアップ
1. GitHubにリポジトリを作って push
2. Settings > Pages > Source を **GitHub Actions** にする
3. Actions > update-and-deploy > Run workflow で `seasons` に `2021 2022 2023 2024 2025 2026`（初回の過去分一括取得。`data/` に取得済みを同梱済みなので省略も可）
4. 以降は cron(土日 JST 16:30/19:30/21:30、平日 21:30)で今季のみ自動更新。変更があるときだけコミット。

## 仕様メモ
- 取得元は `competition_years`(シーズン) × `competition_frame_ids`(1=J1, 2=J2) の検索結果ページ(静的HTML)。カップ戦・プレーオフ・「2026特別」(百年構想リーグ)は含まれない。
- シーズンキー `2026` = 2026/27、それ以前は暦年。節番号は「第N節」から取得。
- クラブIDは公式サイトのクラブURLスラッグ(例 `gosaka`)。リンクが無いクラブは短縮名がID。名称は最新シーズンのもの。
- 未消化(スコア無し)かつ日付が過去の試合は「未消化あり」。消化後は本来の節に計上される。
- `data/*.json` の各クラブに、節ごとの累計(byRound)・監督の変遷(mgr)・各試合(matches=[節,相手ID,ホーム1/アウェイ0,得点,失点])を保存。
- サイト構造が変わって想定外の行があるとエラー終了し、既存データは書き換えない。
- 公式サイトへの負荷配慮のため1リクエスト/2秒、cronは1日数回。個人利用の範囲で。公式サイト側に利用規約・robots.txt上の制限は確認できなかったが(robots.txtは404)、公開・運用はご自身の判断で。
- ローカル確認: `python -m http.server` → http://localhost:8000/ 。手動更新: `python scripts/fetch.py [--seasons ...]`
